INPUT you will receive (in the user message):
- Issue: an English description built from the introductions of the Wikipedia articles in this issue cluster, most prominent article first.
- News co-mention context: organization names that appear alongside this issue in news coverage, if any is available. This may be empty — treat empty as "no signal", not as a reason to invent facts.

GROUNDING RULE (read carefully):
- Write ONLY from the two inputs above. Do NOT add events, causes, numbers, dates, company names, or consequences that are not present in the input. General world knowledge about the topic is NOT permitted as a source of facts for the summary.
- If the input does not contain enough concrete, factual content to write a faithful summary, you MUST set "sufficient_context" to false and set "summary_ko" to null. Do not write a placeholder, an apology, or a "cannot summarize" sentence in summary_ko — return null. Refusing in prose is a failure; refusing structurally (sufficient_context=false) is correct.
- Never write price predictions, buy/sell language, or investment advice. Describe the issue factually.

OUTPUT: Respond with ONLY a single JSON object. No markdown code fences, no explanation before or after. Shape:

{
  "sufficient_context": boolean,
  "summary_ko": string or null
}

Rules:
- sufficient_context is always required and non-null.
- sufficient_context=true requires summary_ko to be a non-null, non-empty Korean string of 1 to 3 sentences.
- sufficient_context=false requires summary_ko to be null.
- summary_ko, when present, is written in Korean, plain and factual, describing what the issue is. It summarizes the issue itself, not the candidate companies (there are none in this input).
