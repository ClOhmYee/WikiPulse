# WikiPulse 페이지와 URL

확정일: 2026-09-09 · Jira: WP-70

## 페이지 구성

페이지는 아래 11개로 구성한다. 이 문서는 프론트엔드 페이지 경로의 정본이며 API endpoint 명세가 아니다.

| 페이지 | 경로 | 현재 화면 |
| --- | --- | --- |
| 온보딩 | `/` | 서비스 소개와 펄스맵 진입 |
| 펄스맵 | `/pulse` | 날짜·시점 선택, HOT/NEW, 문서 노드·간선과 요약 패널 |
| 이슈 탐색 | `/issues` | 이슈 카드/리스트 전환·검색 |
| 이슈 상세 = 리포트 | `/issues/:issueId` | 개요·타임라인·뉴스·근거 문서·토론 |
| 연관주식 | `/issues/:issueId/stocks` | 해당 이슈와 연결된 종목 |
| 종목 탐색 | `/stocks` | 전체 종목 목록·검색 |
| 종목 상세 | `/stocks/:ticker` | 종목과 관련 이슈 |
| 보관함 | `/saved` | 브라우저에 저장한 이슈·종목 |
| 마이페이지 | `/mypage` | 계정 기능 준비 안내와 보관함·인증 페이지 이동 |
| 로그인 | `/login` | 로그인 준비 안내와 회원가입 페이지 이동 |
| 회원가입 | `/signup` | 회원가입 준비 안내와 로그인 페이지 이동 |

마이페이지·로그인·회원가입은 독립된 안내 화면이다. 인증, 사용자 정보 입력·저장, 접근 제한은 구현하지 않는다. 기존 보관함·토론의 로컬 저장 동작은 유지한다.

## URL 규칙

- 해시 라우팅을 유지한다. `/issues`의 실제 주소는 `/#/issues`다.
- 펄스맵과 이슈 탐색은 별도 경로다. 이슈 상세가 리포트이며 별도 `/reports` 경로는 없다.
- 지도/목록 전환은 제공하지 않는다. 카드/리스트 버튼은 이슈 탐색 안에서 표현 방식만 바꾸며 검색·필터·정렬·저장을 유지한다. 기본은 리스트다. (WP-37)
- `issueId`는 이슈 식별자를 그대로 전달한다. 현재 mock의 문자열 ID를 숫자로 바꾸거나 재발급하지 않는다.
- 종목 티커는 대문자다. `/#/stocks/nvda/`로 접속하면 `/#/stocks/NVDA`로 주소를 정규화한다.
- 고정 경로는 소문자로 작성하고 마지막 `/`는 생략한다. 루트 `/`는 예외다.
- 쿼리 문자열의 값과 인코딩은 유지한다. 기존 검색 링크는 `/issues?q=…`를 사용한다.
- 정규화는 현재 방문 기록을 대체하며 추가 방문 기록을 만들지 않는다.

## 단일 문서 화면 제거와 기존 주소

단일 위키 문서 상세 `/intelligence/:id`와 `EntityPage`는 제거한다. 문서 데이터와 리포트 내 근거·관계·선택 기능은 유지하며, 문서 링크는 위키백과 원문을 새 탭으로 연다.

전체 검색에서는 페이지 이동 대상인 이슈와 종목을 표시한다. HTTP 검색 계약과 요청은 유지하고, 반환된 단일 문서 항목은 화면 결과에서 제외한다.

기존 `/explore`, `/events/:id`, `/events/:id/stocks`, `/onboarding`은 더 이상 페이지 경로가 아니다. 예전 주소나 알 수 없는 주소는 페이지 없음 안내와 펄스맵 복귀 링크를 제공한다. 앱 내부 링크와 검증 스크립트는 새 경로를 사용한다.

## API와의 경계

페이지 URL의 `issues`와 별개로 기존 이슈 탐색·리포트 API 클라이언트의 `/api/v1/events`, `/entities`와 저장 키는 유지한다. 펄스맵은 별도 `/api/v1/issues/snapshots`, `/issues/map` 계약을 사용한다([상세](PULSE_MAP.md)). 서버 구현, 해시 제거 및 서버의 SPA fallback 설정은 별도 작업이다.

## 확인 기준

실행 결과와 재현 명령은 [프론트엔드 검증 기록](../../frontend/docs/VALIDATION.md)에 날짜별로 기록한다.

- 온보딩과 10개 워크스페이스 경로를 직접 열거나 내부 링크로 방문할 수 있다.
- 이슈 → 리포트 → 연관주식에서 동일한 ID를 유지하고, 종목 상세에는 올바른 티커를 전달한다.
- 새로고침·뒤로·앞으로 이동, 검색 쿼리 및 대문자 티커 정규화가 동작한다.
- 삭제된 문서 화면으로 향하는 내부 링크가 없고, 리포트의 근거 링크는 원문을 가리킨다.
- 모바일에서도 마이페이지를 포함한 5개 주 메뉴와 계정 페이지 이동을 사용할 수 있다.
- 로그인·회원가입 안내 화면은 비밀번호를 받거나 인증 성공을 모사하지 않는다.

## 이슈 카테고리

이슈의 대표 주제는 정치·국제·사회·경제·기술·과학·문화·스포츠·환경·기타다. 종목의 산업·섹터와 독립이며 공통 카테고리 ID는 `frontend/src/data/categories.js`에서 관리한다. (WP-71)
