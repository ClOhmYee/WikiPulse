## 기록 규칙

각 보고서는 최소한 다음을 포함한다.

- 저장소 상태와 실행 환경
- 입력 범위·파일 크기·체크섬
- 실행 방법과 실제 집계 수치
- `PASS / FAIL / BLOCKED / UNAVAILABLE`
- 실제값과 통제값의 구분
- 명세 변경 필요 여부와 반영 위치
- 재현되지 않은 부분과 다음 검증

원시 로그 전체를 요구사항 명세에 복사하지 않는다. 명세에는 확정된 규칙과 이 색인의
보고서 링크를 남긴다.
