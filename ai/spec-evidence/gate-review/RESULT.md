## 7. 🔴 완전 제거의 진짜 비용 — `max_rev_id`

편집을 안 보면 `spike.max_rev_id`(그 윈도우 마지막 revision)가 안 생긴다. 그게 as-of 링크 앵커다.

```
cluster/driver.py:858     anchored = [s for s in seeds if s.max_rev_id is not None]
cluster/asof_links.py:14  🔴 max_rev_id 가 없으면 현재 판으로 폴백하지 않는다
```

앵커 없는 root 는 **CORE 에서 통째로 빠져 singleton** 이 된다. 2026-09-22 에
`CLUSTER_FETCH_LINKS` 로 만든 멀티 멤버 30건이 그대로 무너지고, replay 대표 텍스트 고정
(명세 v0.3 시점 정합성)도 같은 앵커를 쓴다.

→ 앵커를 **`snapshot_ts` 이하 최신 revision** 으로 바꾸면 편집이 없어도 항상 있다. 별도 작업이다.
