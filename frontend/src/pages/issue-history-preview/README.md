# 과거 이슈 로컬 미리보기

기존 이슈 탐색을 바꾸기 전에 검색·시점별 탐색을 확인하는 **개발 서버 전용 화면**이다. 운영 빌드에서는 경로가 열리지 않는다.

## 실행

`frontend/tmp/issue-history-preview/`에 `metadata.jsonl`, `details.jsonl`을 둔 뒤 `frontend`에서 `npm run dev`를 실행하고 `http://127.0.0.1:5174/#/issue-history-preview`를 연다. 파일이 없으면 화면에 오류가 표시된다. `tmp/`는 Git에서 무시하며 빌드 결과에 포함하지 않는다.

현재 로컬 추출본은 2026-09-24 운영 DB에서 **읽기 전용 조회**로 받은 완료·비폐기 이슈 메타데이터 29,373건과 선택한 대표 문서 3종의 상세 25건이다. 상세는 모든 시점에 있지 않다. 미추출 시점에는 날짜·상태·급증 점수만 보여준다.

동일 `issue_key`를 하나의 대표 문서 묶음으로 표시하고 시점 기록을 나열한다. `live`와 `replay`는 키가 달라 별개 묶음이다. 이것은 **같은 문서의 기록을 탐색하는 기능**이지, 각 기록이 동일한 현실 사건임을 판정하는 기능은 아니다. 이 화면은 운영 DB에 쓰지 않고, 실제 서비스 API나 기존 `/issues` 화면을 변경하지 않는다.
